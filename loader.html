About this tool

A browser port of the structure-building and visualisation tools in AtomForge. Everything runs locally in your browser; files are never uploaded.

Space-group operations for all 230 groups (530 settings) come from the spglib database (BSD-3-Clause). The surface-slab basis follows the algorithm of ASE's ase.build.surface. Rendering uses three.js.

Keyboard: F fit · 1/2/3 view along a/b/c · S select · D distance · A angle · Ctrl+A select all · Delete remove · Ctrl+Z / Ctrl+Y undo / redo · Esc clear.
